ПОТОК / НАСТРОЙКА ВЛАДЕЛЬЦЕМ

Подключите аккаунты
и архив выписок

Настройка выполняется один раз. После неё пользователи смогут регистрироваться и работать со своими данными с разных устройств.

1. Создайте проект Supabase

Откройте Supabase Dashboard, создайте проект и дождитесь готовности. Пароль базы сохраните у себя — в сайт его вставлять не нужно.

2. Создайте таблицы и архив

В проекте выберите SQL Editor → New query. Скопируйте туда весь файл supabase/schema.sql и нажмите Run. Должно появиться сообщение об успешном выполнении.

Скрипт настраивает разделение данных аккаунтов, закрытие месяцев и приватный архив. Повторный запуск не удаляет данные.

3. Заполните config.js

В настройках Supabase скопируйте Project URL и Publishable key. Поля ниже создают файл на вашем устройстве.

Используйте только публичный Publishable key. Secret key, service_role и пароль базы запрещено размещать на GitHub.

4. Настройте регистрацию и письма

В Authentication → URL Configuration задайте Site URL https://glebchik230.github.io/POTOK/. Добавьте в Redirect URLs тот же адрес и https://glebchik230.github.io/POTOK/index.html. Если адрес сайта другой, укажите его.

Включите регистрацию по email/password, подтверждение email и минимальную длину пароля 8 символов или больше. Настройте Custom SMTP для подтверждений и восстановления пароля.

Без собственного SMTP тестовая почта Supabase работает только для адресов команды проекта. Официальная инструкция SMTP.

5. Обновите файлы на GitHub

Сначала сохраните резервный JSON в старой версии сайта. Распакуйте архив обновления. Замените в нём config.js скачанным файлом из шага 3. Загрузите содержимое в корень репозитория POTOK, заменив старые файлы. Сохраните папки vendor, assets, supabase.

В Settings → Pages выберите Deploy from a branch → main → / (root). Дождитесь успешной публикации. Откройте сайт, зарегистрируйтесь и подтвердите email.

Проверка после запуска: импорт тестового файла → скачивание из архива → закрытие прошлого месяца → выход и повторный вход. Второй аккаунт должен быть пустым.

6. Перенесите прежние выписки

В пустом аккаунте нажмите «Перенести данные» — кнопка появится, если прежние данные есть в этом браузере на том же адресе сайта. Или восстановите резервный JSON. Оригиналы старых файлов загрузите повторно: раньше они не сохранялись.

Внутри приложения откройте «Как пользоваться»: там есть схемы загрузки, проверки, сортировки, закрытия месяца и архива.
